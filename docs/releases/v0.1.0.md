First release of Guarded Batch Operator, a Go Kubernetes controller using embedded OPA/Rego policies to gate bounded batch Jobs.

- Immutable, namespaced `GuardedRun` requests reference administrator-maintained template, policy, and evidence ConfigMaps.
- Fail-closed evaluation; `EvaluateOnly` reports permission without creating a Job.
- Owned Job observation, restart recovery, status conditions, and Events.
- Namespace-scoped runtime permissions without Secret reads.
- Go race tests, Rego policies, real Kubernetes API integration, vulnerability analysis, and actual Kind Job lifecycle qualification on ephemeral Spot workers.

This initial release targets **Linux AMD64**. The API is `v1alpha1`; production backup adapters, scheduling, global concurrency limits, and exactly-once external effects are outside its scope. Demo evidence and workloads are synthetic.

Assets include the controller binary archive, a loadable Docker image archive, `install.yaml`, `release.json`, and `SHA256SUMS`. The published installation manifest pins the registry image by digest. The image runs as UID/GID 65532 with a scratch filesystem. The Docker archive and registry image contain the same controller image; release metadata records its image ID and source commit.

Verify downloaded files with `sha256sum --ignore-missing --check SHA256SUMS` before use. To load the image archive locally, run `docker load --input guarded-batch-operator_0.1.0_image_linux_amd64.tar.gz`.
